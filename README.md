# Sistema de Agentes Literarios - Colectivo "El Cronista & La Pluma"

Este directorio contiene la arquitectura, contratos, memorias y prompts operativos para la co-creación literaria de alta gama inspirada en el lirismo de **Patrick Rothfuss**, aderezada con **ironía mordaz, ritmo prosódico y rigor de continuidad**.
